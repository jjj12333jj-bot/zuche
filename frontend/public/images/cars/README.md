# 车辆图片说明

本目录下为 24 款车型的实拍照片，每款 3 张（前 45°、正面、后 45°），共 72 张。

- 尺寸：1200 × 800，JPEG，质量 82
- 命名：`car-{车型ID}.jpg`、`car-{车型ID}-2.jpg`、`car-{车型ID}-3.jpg`
- 用途：随前端静态资源离线分发，页面不请求外部图床

## 图片来源

取自汽车之家车型图片库（`car.autohome.com.cn`）公开车型图，下载后统一裁切压缩，
仅用于本项目教学演示，不作商业用途。原始版权归各汽车厂商与拍摄方所有。
