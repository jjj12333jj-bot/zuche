## S4 复验（21:30-21:45，全部通过）

### 排障经验（下次直接复用）
- **接口前缀**：订单是 `/api/orders`（复数），不是 `/api/order`。写成单数会命中 Spring 静态资源兜底，抛 `NoResourceFoundException`，被 GlobalExceptionHandler 吞成 `500 系统繁忙`，很容易误判成代码 bug。
- **不要用 nohup/& 起后端**：沙箱会在命令结束后回收进程（表现为日志已写、端口已消失）。必须用 Bash 工具的 `run_in_background` 直接跑 `java -jar`。
- **python 不认 git bash 的 `/tmp`**：`open('/tmp/x')` 直接 FileNotFoundError。curl 认（MSYS 映射），python 不认。跨工具传文件一律用项目内 `.tmp-xxx/` 目录，验完删。
- **本机没有 PIL / ImageMagick**，`Add-Type` 也被安全策略拦。要看截图里某个像素的真实颜色，用标准库 `zlib+struct` 手写 PNG 解码（脚本思路：IHDR 取宽高/通道 → IDAT zlib 解压 → 逐行反滤波 0~4），再按目标色 RGB 统计 y 聚类。比肉眼判断可靠得多。

### 口径（答辩会被追问，必须记牢）
- **净营收** = 租金实收 − 租金退款 + 违约金。**押金是代收代退，不进营收**。
- 平均客单价 =（累计租金实收 − 租金退款）÷ 累计已支付订单数。
- 累计净营收 307,974.79；近 30 天净营收 276,118.91 = 30 天租金 276,463.27 − 退款 944.36 + 违约金 600。**已用 SQL 交叉验证，两个口径能对上**。
- 漏斗五级取自订单自身时间戳（pay_time/pickup_time/return_time/status），不用 status 反推，取消订单已发生的动作不丢台阶。
- **刻意不做"车日利用率"**：种子数据同车存在时间重叠订单，按车日算会得到 563%，展示出来是错的。改用"单车产出 = 租金 ÷ 车辆数"。
